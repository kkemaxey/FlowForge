# FlowForge Checkpoint API

A standalone FastAPI server for the CSC 480 individual checkpoint. It exposes a
single read-only endpoint, `GET /api/workers`, which returns a hard-coded list
of warehouse workers and robots. No database, authentication, or frontend.

## Prerequisites

- macOS
- Python 3.14 (developed and tested on Python 3.14.6)

Check your Python version:

```bash
python3 --version
```

## Install

From the project root (`flowforge-checkpoint/`):

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

Start the server on `127.0.0.1:8000`:

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Leave this running. Stop it with `Ctrl+C`.

## Example request

In a second terminal:

```bash
curl http://127.0.0.1:8000/api/workers
```

Exact JSON response:

```json
[{"id":1,"name":"Alice Nguyen","type":"human","speed":1.4,"cur_x":12,"cur_y":5,"status":"busy","enabled":true},{"id":2,"name":"Rover-7","type":"robot","speed":3.2,"cur_x":0,"cur_y":0,"status":"idle","enabled":true},{"id":3,"name":"Hauler-12","type":"robot","speed":2.5,"cur_x":34,"cur_y":18,"status":"busy","enabled":false}]
```

For a formatted view, pipe it through Python's JSON tool:

```bash
curl -s http://127.0.0.1:8000/api/workers | python3 -m json.tool
```

Interactive API docs (auto-generated by FastAPI) are available at
<http://127.0.0.1:8000/docs> while the server is running.
